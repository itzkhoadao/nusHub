# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue or discussion.
Use GitHub's private vulnerability reporting form instead:

https://github.com/itzkhoadao/nusHub/security/advisories/new

Include the affected route or component, reproduction steps, potential impact,
and any suggested remediation. Do not include real user credentials or personal
data. Reports will be acknowledged as soon as practical and coordinated fixes
will be prioritized according to severity.

## Supported version

Security fixes are applied to the current `main` branch. This project does not
currently maintain older release branches.
